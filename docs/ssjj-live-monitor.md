# SSJJ 实时监测浮窗

更新：2026-10-14。

- 删除常驻的路线说明，改为标题、怪物数量卡片、XYZ 坐标、折叠详情和录制操作。保留置顶、不抢焦点、标题拖动、F8 开始/停止及未保存路线保护。
- 小怪包含普通怪和精英（品质 0–2），Boss 为品质 ≥3。仅统计客户端已加载、启用、血量大于零且未死亡的 Bot；排除友方、本人、预测副本和销毁对象，按角色 ID 去重。不是整张地图尚未加载或尚未出生的怪物总数。
- 统计使用独立读取句柄和后台线程，每轮间隔 0.5 秒，不阻塞路线的 20 Hz 采集。集合变化、状态冻结、断线或读取失败时清空数量；超过 1.5 秒或地图与坐标快照不符时显示“—”，有效空集合显示 0。
- 复用原研究探针的实体集合遍历和组件识别，探针与正式功能共用同一实现。游戏分类依据为本地保存的 `HpProgressDataSystem.UpdateTarget` 和 `PlayerDrawMapImageSystem.DrawRpgPokeMapImage`；友方依据为 `PlayerEntity.IsFriendly`。
- 验证通过后台单元测试和编译检查；对已运行游戏的一次只读采样得到地图 100001、小怪 0、Boss 0，遍历约 7.2 ms。该采样不代表已覆盖有怪战斗场景。未启动或目视检查界面，未构建或打包。
- 执行「键鼠连续路线」时会自动出现：这条路线一开始执行就把浮窗放回桌面（之前关掉了也会自动打开，仍沿用不抢游戏前台的显示方式），执行结束只收回这次由执行自动打开的那一个；手动点「游戏坐标」打开的浮窗不受执行影响。
