# 坐标浮窗与原生路线动作集成

日期：2026-10-11。目标是复用已有坐标读取与跟随控制器，在现有 Tk 编辑器中显示状态、录制路线并作为普通脚本动作执行。用户另要求游戏后台运行并同时使用电脑；本次窗口消息探测未产生移动，因此该能力尚未完成。用户要求不推送，交付仅本地提交。

## 设计与验证

- `SSJJMonitor` 在独立线程读取本人状态，通过锁保护快照和路线捕获；Tk 主线程只更新文字。错误后关闭读取句柄并重连，过期快照不能录制，状态时间冻结会报错。
- `RouteCapture` 按距离保存沿途点与终点，切图、死亡、传送后拒绝生成有效路线。
- 编辑器“游戏坐标”打开不激活浮窗；录制结束插入 `ssjj_route`，点位内嵌在普通脚本 JSON。关闭/退出时保护未插入数据。
- 播放器原生分发路线动作，复用已跑通的跟随控制器和父进程输入检查，保留暂停、停止和守卫异常传播。
- 36 项相关后台测试通过，包括保存重载、监控线程退出、原生动作适配及退出保护。没有启动或操作软件界面进行检查；没有构建或打包。此前地图 100001 的 39 点路线已实际跑通；本次 UI 集成不额外声称视觉验证通过。
