# 多实例定时插件

用户要求可新增多个定时条件插件，每个卡片带启用勾选框，新建默认启用。复用现有单插件状态机、串行播放器、识别条件和独立编辑窗口。

1. `plugins_runtime.py` 用按 ID 索引的实例集合替换单实例；配置保存为列表。独立计时、独立保存/禁用，一个实例运行时不领取其他插件。F12 禁用全部。`interval_plugin.py` 允许启用的未配置草稿，待配置状态不识别、不执行。
2. `plugins_page.py` 增加新增按钮、命名、逐卡启用勾选框与滚动列表；右键按 ID 编辑。复用 ttkbootstrap 的 ScrolledFrame。保存入口和停止入口改为集合，不保留旧单实例配置路径。
3. 后台验证默认启用、多实例独立保存与时钟、串行执行、F12、失败持久化、卡片交互和滚动组件接入。运行相关/必要全量测试与语法检查，只提交当前任务变更，不打包、不推送、不启动界面。
