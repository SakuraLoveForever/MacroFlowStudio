# 键鼠路线回放前自动返回起点

用户要求：不再提示手动回到起点；先从当前位置走到录制起点，再执行原录制键鼠动作。

设计：复用 `RouteContext` 和 `follow_route`，以当前位置为导航的第一点，将到起点的直线分为不超过 500 单位的段，沿用已有校准、最短转向、停走控制与失焦/暂停/卡住释放。导航终点增加可选 `final_yaw`，停稳后对齐录制初始朝向。回起点完成且二次状态检查有效后才创建录制输入会话、启动原动作时间轴。起点到达容差 20；回放中偏差阈值仍为 150。

范围：直线返回，不声称具有地图绕障或跨楼层寻路。保持当前工作区、无新依赖、不启动界面、不发送实机测试输入、不构建或推送。

- [x] 先补失败测试：远距离起点自动返回、原回放时间轴不计入准备耗时、最短最终朝向、准备失败不回放。
- [x] 扩展已有连续导航终点朝向，接入路线录制回放准备阶段。
- [x] 后台模拟：1600 单位外返回、到达后朝向对齐、阻挡释放；267 项相关测试通过。
