## 已确认并修复的问题

| 问题 | 触发条件及影响 | 修复 |
|---|---|---|
| 不同更新回调被合并 | 两个普通函数或同一对象的不同内置方法使用相同 batch_key，前一个回调及事件被替换 | 使用 Python 自身的回调相等比较，删除错误的自定义判断 |
| 更新队列异常后停转 | 一个回调抛异常，余下事件丢失，定时泵不再调度 | 逐项交付并经 Tk 标准错误通道报告；finally 中保证重新调度 |
| OCR 裁剪超出预期区域 | 检测区域从截图左/上边界外开始，裁剪后的右/下边界被错误扩大；完全在外的区域也可能识别到内容 | 原始坐标计算另一端边界，再取交集 |
| 刷新率设置失败仍报成功 | 宽高正确但刷新率仍错误，底层设置返回失败 | 复用包含刷新率和驱动 1 Hz 容差的现有判断 |
| 保存失败损坏旧数据 | 磁盘写满或复制中断时，直接覆盖脚本、工作流、设置或唯一备份，旧文件被截断 | 同目录临时文件写完后原子替换；模块仓库复用同一个 JSON 写入函数 |
| 覆盖历史备份重名 | 同一脚本在同一时间戳内连续保存，两个历史版本共用路径 | 标准库生成独立历史文件名，失败时删除不完整副本 |
| 零间隔文本忽略停止/暂停 | char_delay_ms=0 时逐字符循环没有检查停止信号，F12 后仍继续输入 | 每个字符发送前检查暂停及停止 |
| 播放器错误后不能重用或漏松按键 | 显示参数准备、作用域退出或统计回调异常，running 未复位；作用域退出异常还会跳过按键释放 | 易失败参数在进入运行态前准备；finally 保证释放输入及状态复位，再调用统计回调 |
