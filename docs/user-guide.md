## 录制与回放

- **智能轨迹识别**：鼠标锁在窗口中央时记录原始相对轨迹（游戏视角转向，高频采样 ≤16 ms）；离开目标窗口后恢复普通桌面坐标（默认间隔 20 ms，可调 10–500 ms）
- 每次开始录制前自动把目标窗口切换为英语（美国）输入法；F8 重新录制直接覆盖当前文档（有未保存修改时先弹确认），保存已存在的脚本文件时会提示是否覆盖，覆盖前旧版本自动归档到 `backups/overwritten/`（时间戳历史，可找回）
- **回放**：支持从指定行开始、按次数重复、断点恢复、连续点击、点击鼠标当前位置

## 脚本编辑

"脚本编辑"页支持插入以下动作，双击动作可编辑，按住 Shift/Ctrl 多选：

| 动作 | 说明 |
|---|---|
| ⏱️ 延时 | 等待固定毫秒数 |
| ⌨️ 键盘 / 敲击 | 按下/松开/敲击按键，插入时可按键自动检测 |
| 📝 文本 | 输入文字 |
| 🖱️ 鼠标移动 / 按键 / 点击 / 连续点击 | 屏幕点选记录坐标，点击可选左/右/中键 |
| ↔️ 拖动 | 从起点按住拖动到终点松开（屏选标注或手动输入坐标），可选步数/时长/鼠标键 |
| 🎡 滚轮 | 在指定位置向上/向下滚动指定格数（工具栏「↕ 滚轮」，可屏选坐标） |
| 🖼️ 识图 | 模板匹配找图（见下） |
| 🔤 识别文字 | RapidOCR 离线识别区域文字（见下） |
| 💬 浮动提醒 / 注释 | 屏幕提示 / 备忘文字 |
| 🔗 引用脚本 | 实时读取另一脚本执行（内嵌执行，不跳转）；动作列表里在该行**右键 →「▶ 单独执行此动作…」**可只把这个被引用脚本跑 1~N 次（默认 1 次，外层脚本不动），右键菜单里还能在新窗口打开它 |
| 🚀 打开 / 关闭软件 | 启动程序（带参数）/ 优雅或强制结束进程 |
| 🖥️ 分辨率 | 从左侧“分辨率样式”设置中选择样式；参照窗口可留空——留空直接修改**当前软件所在显示器**，选了窗口则只修改该窗口所在的显示器 |
| 🧭 跳转 | 跳转到目标动作行、脚本开头或脚本结尾 |
| 📌 前置窗口 | 从「添加动作」选择目标进程的可见窗口并前置；后续键鼠动作以该窗口为前台目标，直到再次前置其他窗口或重新绑定目标 |
| ⭐ 特殊模块 | 重新执行工作流 / 结束当前最里层脚本并继续 / 跳到脚本实际最后一行 |
| 🧰 模块引用 | 插入已保存的模块对象（见"模块对象"） |

需要离开游戏操作其他页面时，可依次添加「前置窗口」（选择该页面的进程窗口）→「键盘」（敲击 `LWIN`）→后续操作。返回游戏前，再添加一次「前置窗口」选择游戏窗口。

### 编辑与局部执行

支持撤销／重做、多选、整块上移／下移、向下复制。保存后清除撤销历史；打开或新建其他脚本前，可选择保存、放弃修改或取消。

| 操作 | 执行范围 |
| --- | --- |
| 右键「从此行开始运行」 | 从当前行开始，继续执行后续动作 |
| 右键「单独执行此动作…」 | 只执行该行，可设 1–999999 次，默认 1 次 |
| 选中连续多行后「循环执行片段…」 | 每轮按顺序执行选中动作，不执行片段外的行 |
| 引用脚本行「在新窗口打开引用的脚本」 | 打开被引用脚本进行编辑 |

单行动作仍保留自己的延时、识别等待、失败处理、内部步骤及重复次数。跳转、结束脚本和重启工作流等控制动作只记录目标与结果，不继续执行目标行；阻塞等待仍需等到触发或按 `F12`。

循环片段的跳转目标若落在片段外，会记录并结束本次片段；片段外的脚本全局模块不注册。连续选择可用 Shift；脚本动作也支持 Ctrl 选中两端，选区左侧会显示实心竖条。

### 分辨率与窗口

在「执行设置 → 分辨率样式 → 设置…」中维护样式。动作保存宽高、刷新率和缩放比例快照，缩放默认 100%。

参照窗口留空时，修改软件所在显示器；选择窗口后，优先修改该窗口所在显示器。窗口未打开时回退到软件所在显示器，记录提示并继续工作流。

「添加动作」或「⋯ 更多」中的 **「插入脚本指定行…」** 可先预览所选脚本每一行，再指定起始行与终止行，把这段连续动作复制到当前脚本的选中位置。区间内跳转会映射到新行；若跳转指向区间外，需扩大范围后再插入。

## 识图与文字识别

左侧“执行设置 → 局部执行时启用”可分别控制脚本全局模块和工作流全局模块；从选中行运行、单独执行行或工作流步骤、循环片段时生效，两项默认勾选。

**模板匹配识图**（找固定图案）：

- **区域**：全屏 / 绑定窗口 / 自定义区域（按住左键拖框选）
- **阈值**：相似度下限
- **超时**：等待超时毫秒数 + 检测间隔，超时后继续 / 跳转指定行 / 停止
- **找到后**：继续 / 点击（识图区域中心或自定义坐标）/ 跳转指定行 / 直接结束当前脚本执行工作流下一项
- **二次识别**：命中后可选另一张模板再次确认

**文字识别**（读会变化的文字，与识图互补）：引擎为 RapidOCR 3.9.2（CPU 离线运行，使用本地 PP-OCRv6 small 模型）

- 框选识别区域（留空 = 全屏），或绑定目标窗口
- 期望文字按"包含 / 等于"匹配；留空 = 识别到任意文字即命中
- 支持轮询等待与超时后继续 / 跳转 / 停止；结果显示在状态栏与执行小窗
- **失败后执行代码段**（脚本行级）：识图、识别文字、识别数字比较、多条件识图点击、列表逐行条件点击都能各自勾选；识别不到 / 超时 / 阻塞超时后先执行这段动作（添加 / 编辑 / 移除 / 上移 / 下移，支持延时、键盘、文本、点击、连续点击、移动、识别模块、引用脚本、打开关闭软件、提醒、前置窗口、跳转脚本尾、结束当前脚本等），再走"失败后"分支

### 列表逐行扫描

- 列表逐行扫描适合处理“列表中每一行都按左右条件判断，再点击某一行”的界面：先框选列表区域和首行左侧 / 右侧 / 点击区域，再填行高（可点「框选第二行基准…」自动推算）。脚本执行到该动作时会重新截取当前屏幕的列表区域，按行高逐行扫描，左右条件同时满足后点击该行。动作带**结果分支**：命中并点击后、以及整轮扫描没有任何行满足条件时，都可以设置为「继续下一行 / 跳转到某一行对象 / 结束当前最里层脚本」
- 失败时还可以先执行行级"失败后执行代码段"，再走失败分支。

测试识别是两个独立按钮，都只识别、不点击、不跳转：

- **测试当前屏幕（不点击）**：截取当前屏幕，把每个识别单元格框出来并显示识别文字
- **测试选择的图片（不点击）**：对「选择图片…」选定的整屏截图做同样的识别（图片需覆盖列表区域）

结果窗口铺满屏幕，绿框=命中、红框=未命中；文字 / 数字条件显示 OCR 文字（识别不到显示「未识别到文字」），图片条件显示「图片命中 / 图片未命中」。顶部工具条可以拖动，支持切换原图 / 识别结果，图片也可以使用鼠标滚轮放大或缩小。

## 模块对象

"模块对象管理"把识别设置保存为可复用的独立对象，分类：**切换 / 工作流全局 / 脚本全局 / 特殊**。

- **独立身份**：按 ID 引用而非图片路径，同一张图可建多个不同模块，互不覆盖
- **识别设置**：模板、区域、阈值、持续时长、识别方式（模板图片、识别文字、读取数字或无需识图）
- **成功动作 + 附加代码段**：命中后执行的动作，完成后可继续执行一段附加动作（支持跳转、前置窗口等固定动作）
- **超时代码段**：独立设置"连续未识别"超过时限后执行的动作
- 仓库支持拼音排序、批量加入 / 批量从脚本删除、双击编辑、撤销移除；**右键任意模块 →「▶ 测试指定次数…」**可独立测试 1–999999 次（默认 1 次），禁用模块也可测试且不会改变启用状态

### 读取数字模块

在"模块对象管理"新建切换模块，把"识别方式"设为**读取数字**并框选数字所在区域。运行时会把 OCR 数字段按屏幕从左到右拼接为整数（例如 `0`、`0`、`7` → `7`）。

插入脚本时设置"比较数字"与两路结果：**等于 / 不等于或未读取到**。两路均可继续下一行、跳转到稳定行对象或结束当前最里层脚本；未读取到数字时按模块的"阻塞识别 / 未识别时限"重试，非阻塞超时后走失败分支。

阻塞模块插入到具体脚本后，双击该引用行可单独开启**阻塞超时后跳过**并设置毫秒数；该选项默认关闭，只影响当前脚本行，其他脚本引用仍按模块原设置阻塞等待。

同一处还能勾选**失败后执行代码段**（脚本行级）：识别不到或阻塞超时后，先执行这段代码段（添加/编辑/移除/上移/下移，支持延时、键盘、文本、点击、连续点击、移动、识别模块、引用脚本、打开/关闭软件、提醒、前置窗口、跳转脚本尾、结束当前脚本等），再按"失败后"分支继续下一行 / 跳转到行对象 / 结束当前最里层脚本。模块对象自己的"超时代码段"仍由"模块管理…"统一设置，两者互不影响。

## 工作流

"工作流"页按顺序组织多个脚本，每一行（步骤）可设置：

| 设置项 | 说明 |
|---|---|
| 📄 脚本 | 双击更换 |
| 🔁 执行次数 | 剩余次数制（失败或手动停止不扣减，减到 0 显示"次数用完"）；可设 0 或勾选**不计次数**（每轮只执行一次）；可配置**第 2 次及以后从指定行开始** |
| ⏳ 开始前等待 | 执行前等多少毫秒 |
| ⏱️ 重复间隔 | 同一脚本相邻两次执行之间等待时间，默认 1000 ms |
| ✅ 启用 / 禁用 | 禁用行变灰自动跳过，不扣次数 |
| 🌐 全局模块 | 步骤可挂接工作流全局模块 |

### 调试与管理

| 操作 | 行为 |
| --- | --- |
| 从选中行运行 | 从该步骤继续工作流 |
| 右键「单独执行此步骤…」 | 只运行该步骤的脚本，可设 1–999999 次（默认 1 次），不扣减保存的剩余次数 |
| 连续选择后「循环执行片段…」 | 按轮重复选中步骤，每轮各执行一次，不扣减剩余次数，也不执行片段外的步骤 |
| 统一设置参数 | 批量修改次数、开始前等待与重复间隔 |
| 修改名称／复制为新工作流 | 保存时同步重命名，或立即打开独立副本；不覆盖已有文件 |

右键步骤可在新窗口或当前编辑器打开脚本；删除步骤可撤销。连续选择使用 Shift，选区左侧显示实心竖条。脚本文件丢失的步骤标红，并在执行时提示原因。

定时执行接受 `YYYY-MM-DD HH:MM:SS`，留空则立即运行。等待期间程序必须保持运行。

工作流是普通文件（`workflows` 目录下的 JSON）：新建 / 打开 / 保存，界面上显示的就是该文件的内容，修改后保存即生效。

### 全局检测

工作流执行期间，启用的全局模块持续检测（共享同一轮截图，不重复截屏），满足条件即触发：

- **触发冷却**：每个全局模块可单独设置，默认 2000 ms；目标持续存在时，冷却到期即可再次触发，不要求图片先消失
- **打断与恢复**：触发时暂停当前脚本并保存断点，执行模块的成功动作后自动恢复原脚本
- **点击**：点击识别区域中心或自定义坐标；点击前确保目标窗口在前台
- **重启工作流**：触发后可重新执行工作流，并支持配置跳转行对象（模块配置表单 / 代码段动作编辑两处可设）；未指定时使用工作流页面统一设置的默认跳转行（默认第 1 行）

## 执行与设置

- **强制专注模式**（默认关）：切换英语输入法 + 系统级键鼠锁定（`BlockInput`），阻止误操作；执行时 F8 暂停并释放键鼠，再按 F8 重新锁定并继续，F12 紧急停止
- **前台恢复**：开启「执行前置窗口」时，每次播放开始把目标窗口激活一次（窗口已在前台时不做任何激活，避免游戏弹出“点击游戏画面继续操作”）；全局检测每次截图后校验一次绑定窗口是否仍在台前，失焦才抢回（正常时零开销）。点击/移动坐标越界会被收敛进目标窗口，防止点出窗口抢走焦点
- **执行前置窗口**：独立开关，可指定另一个窗口先被激活；左侧「两次前置间隔」可设置该窗口与目标窗口两次前置之间的最短时间（毫秒），不增加目标窗口前置后的脚本等待。取消勾选后，工作流步骤脚本自己保存的前置窗口同样不会执行。执行时前置窗口未打开（或已关闭）会自动跳过前置激活并继续执行，不中断脚本
- **悬浮小窗**：执行 / 录制时置顶小窗（各自独立开关），显示进度与动作日志
- **系统托盘**：勾选「启动到托盘」时开机常驻托盘，双击托盘图标恢复窗口；点关闭按钮保存草稿后直接退出（需要继续后台运行请先最小化到托盘），托盘菜单可暂停/继续当前执行、恢复窗口或退出；脚本侧栏、工作流页和执行小窗也有暂停/继续按钮
- **快捷键提示音**：录制开始/结束、执行、完成、紧急停止各有不同音调，可测试
- **快捷键脚本**：侧栏「快捷键脚本 → 设置…」把脚本绑定到单个按键（字母、数字、F1-F12、方向键等，F8/F9/F10/F12 与纯修饰键除外）。**录制**时按快捷键，快捷键本身不会录进当前脚本，脚本回放的键鼠输入会被录进去；**执行**时按快捷键，绑定的脚本在独立播放器中并行执行，不打断当前脚本/工作流；F12 同时终止所有快捷键脚本。绑定保存于 `app_settings.json`，重启自动恢复
- **读取当前坐标**：实时显示光标坐标与所在窗口，用于手工填写坐标
- **分辨率适配**：脚本记录录制时**目标窗口所在显示器**的物理尺寸，同屏执行坐标 1:1，换屏/换分辨率按比例映射；识图/全局检测的模板匹配也按显示器宽度比缩放模板。多显示器不同缩放（笔记本 200% + 外接屏 100%）时软件按每块屏各自的 DPI 渲染，接/拔外接屏不再影响同屏坐标

## 备份与日志

- **定时备份**：间隔固定为 `1h` / `1天` / `1周`，扫描已配置的脚本目录备份到 `backups/scripts/`；每个脚本固定对应一个目标文件，不生成多份历史副本
- **开机自启动**：写入当前 Windows 用户的启动项；取消勾选即删除
- **启动到托盘 / 启动自动执行工作流**：可同时启用，自动运行结束后仍保持在托盘，双击托盘图标恢复窗口
- **运行日志**：自动写到 `logs/年-月-日/MacroFlow_启动时间_进程号.log`，每次启动独立文件，日志页的"打开日志目录"可直接查看

## 文件目录

程序首次启动在 exe 同目录创建：

```
MacroFlowStudio/
├── MacroFlowStudio.exe   # 主程序
├── rapidocr_ocr/          # RapidOCR + CPU ONNX Runtime + 本地模型/依赖/许可证（按需加载）
├── scripts/              # 脚本
├── workflows/            # 工作流
├── images/               # 建议存放识图模板
├── backups/scripts/      # 定时备份
├── logs/                 # 运行日志（按日期 / 会话拆分）
└── app_settings.json     # 全部侧边栏配置与窗口绑定
```

"打开"按钮可读取其他目录的 JSON 脚本；模板图片建议放 `images` 并在识图动作里用相对路径（如 `images\start_button.png`），方便迁移。

## 专项设置

### 时间、搜索与关闭软件

模块管理和模块选择均支持跨分类保留关键词搜索。模块编辑中的“识别前强制等待”会先完整等待再识别；所有时间输入默认显示秒（s），保存仍为毫秒。关闭软件的“正常关闭”超时会停止，不再自动强杀；可填写“同时等待退出的进程”，防止辅助进程尚未退出时就重新启动。

### 识别等待规则

模块识别设置：目标条件选择“出现 / 消失”；等待规则选择“未命中立即跳过 / 限时等待 / 一直等待”。限时等待从开始识别时计时；需要先等一段时间再识别，请编辑脚本中的模块引用行，设置 **识别前等待**（例如填写 5 s = 5 秒）。检测间隔、触发冷却、识别确认与备用识别在“高级识别设置”中展开；收起不清除参数。

### Python 逻辑

支持在 VS Code 中编写 Python 逻辑：定义 `main(ctx)`，使用“Py 逻辑”动作引用 `.py` 文件，或直接打开 Python 文件再保存为普通脚本。每次运行读取最新代码，支持工作流、快捷键、暂停与 F12 停止。参见 [Python 脚本接口与示例](python-scripts.md)，示例文件为 `examples/python/hello_macro.py`。

### 持续状态与进程监控

进程监控：在模块编辑中选择**进程检测**，从下拉列表选择进程（每次展开刷新当前进程），选择“连续未检测到”，设置 30 秒并添加启动程序等自定义步骤。进程名不区分大小写；同名进程有一个运行即视为存在，无需图片或识别区域。

模块编辑中可启用**持续状态触发**，选择“连续检测到”或“连续未检测到”，设置持续时长并添加自定义步骤。例如连续 30 秒未检测到游戏大厅时执行返回大厅步骤。状态变化或检测失败后重新计时；全局模块在同一持续状态内只触发一次，反转后重新计时。

### 工作流自动恢复

**工作流自动恢复**：完整工作流运行时自动启用。截图连续失败 30 秒后停止当前执行并释放输入锁，待旧工作线程与检测线程退出、屏幕连续两次可截图后，从第 1 步重新运行，保留各行剩余次数，不重复启动延时或排期。工作线程、全局检测请求或界面心跳失联 60 秒时先请求停止；10 秒内仍未完成交接，由独立后台看门狗结束旧软件进程、重启软件并等待屏幕恢复。正常延时、暂停和重复循环不会因为停留在同一步被重启。F12、退出软件或手动开始另一项执行会取消待恢复任务；测试模式、单独脚本和选中片段不启用自动恢复。故障堆栈与看门狗记录保存在当天日志目录的 `workflow_recovery_*` 文件中。

## 使用边界

- 轨迹采样间隔至少 10 ms，识图检测间隔至少 50 ms，单次录制最多 200,000 个动作。
- 停止或异常退出时，软件会尽量释放仍按下的按键与鼠标键。
- 执行期间阻止屏保、熄屏和自动睡眠，不修改电源设置。
- 使用前请确认目标软件允许宏或自动化操作。
