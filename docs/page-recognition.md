# 页面识别与「页面」动作

## 为什么需要它

大厅是 Adobe AIR/Flash，没有可用的 UIA/MSAA 树、CEF DOM 或页面状态 API；战斗端是 Unity Mono，虽有只读内存线索但需要进对局核验。以前的做法是每个按钮都用「识图模块 + 阻塞等待 + 超时」去试，页面已经切过去还在等 3 秒，或者没切过去又白点一次。

页面识别把「现在是什么页面」变成一次截图判定：整屏截图 → 标准化灰度特征 → 与页面库做点积，取最相似的页面。执行引擎在等待间隙顺带刷新当前页面，脚本可以按页面直接走下一步。

## 页面库

- 目录：`images/全屏`（固定，不随模块模板目录变化）。
- 每张整屏截图就是一个页面，文件名去掉扩展名就是页面名，例如 `全屏_回到大厅.png` → `全屏_回到大厅`。
- 截图要求：与运行时同一窗口模式（全屏/铺满 16:9），不含鼠标指针；不同分辨率会缩放到 64×36 后比较。
- 目前库里有 84 张（大厅各子页面、弹窗、战斗加载/结算等），也是「点击游戏画面」这类瞬时状态的来源。
- 新增页面：把整屏截图按页面名放进该目录即可，对话框会立即列出；页面文件被用户改过时执行端会重新读取（每个播放实例缓存一次特征）。

## 「页面」动作

界面：脚本工具栏「◫ 页面」。

| 字段 | 含义 |
| --- | --- |
| 页面 | 页面库中的页面名 |
| 判定方式 | 等待出现 / 等待消失 / 立即判断 |
| 相似度阈值 | 与页面截图的相似度，默认 0.97 |
| 超时时间 | 等待出现/消失的最长时间；勾选「一直等待」或填 0 表示不超时 |
| 检测间隔 | 轮询间隔，默认 150 ms |
| 成功后点击 | 命中后点击 `点击坐标`，支持左/右/中键与次数 |
| 超时后 | 继续下一行 / 结束当前脚本 / 跳转到脚本行 |
| 提醒 | 命中后显示浮动提醒 |
| 执行前延时 / 成功后延时 | 进入动作前后各等多久 |

执行语义：

- 等待出现：页面相似度 ≥ 阈值立即成功，否则按间隔重试到超时。
- 等待消失：页面相似度 < 阈值立即成功，否则重试到超时。
- 立即判断：只抓一帧，命中成功；不命中直接走「超时后」分支（可用于「如果在大厅就点进战斗，否则跳到别处」）。
- 命中后可点击固定坐标（按 1920×1080 记录，运行时自动缩放），随后继续下一行动作。
- 等待期间会记录「页面切换：xxx（相似度 99.3%）」到运行日志，便于确认脚本是不是卡在错误的页面假设上。

## 执行期页面跟踪

播放器在长时间等待（`_wait` ≥ 200 ms 的切片）里每 250 ms 抓一帧判定页面，页面变化时写一条日志。这也让 Python 逻辑能读到当前页面：

```python
def main(ctx):
    if ctx.page_is("全屏_回到大厅"):
        ctx.run_module("进入战斗")
    ctx.log(f"当前页面：{ctx.page()}")
```

## 性能

| 项 | 实测（本机 1920×1080） |
| --- | --- |
| 单帧特征提取（含缩放） | ≈ 1.3 ms |
| 与全部 84 个页面匹配 | 约 0.2 ms 的矩阵乘 + 抓屏 |
| 首次加载页面库（解码 84 张 PNG） | ≈ 2.1 s，每个播放实例一次 |
| 执行期页面跟踪开销 | 4 帧/秒抓屏，约 5% 单核 |

## 已知风险

- 库里有 6 组「同底图 + 局部元素差异」的近似页面（异页相似度 0.95–0.998，提高分辨率也分不开）：
  - 专家 / 专家5 / 退出队伍；
  - 关闭全区找房 / 刚开始 / 游戏中测试 / 游戏中测试2；
  - 天降神器 / 结算关闭；
  - 开始战斗 / 战斗引擎；
  - 极速模式开始战斗 / 邮件（最难，任何整页方法都 0.94+）；
  - 王者乱斗 / 极速模式。

  页面动作「等待某个具体页面」不受影响（直接比对该页面截图）；但执行期「当前页面」名称可能在组内抖动，因此追踪带 0.02 的 margin 与「优先保留上一页」规则，日志里会写「与 X 相近」。
- 大厅页面动画/倒计时对整页特征影响很小：实测同页 10 帧自相似 0.9997–0.9999、分数 0.9954–0.9959；2% 面积动画约 0.977，计时器覆盖约 0.973，所以阈值取 0.97。若某页面实机分数更低，可在该动作里单独调低阈值，或补一张该页面状态的截图（同名会覆盖）。
- 战斗中的画面不在页面库里，战斗内仍应使用战斗识图/模块；战斗端 `FreeUiManager` 只读读取器完成后可作为补充信号。
- 抓屏用目标窗口所在的显示器；窗口化且带黑边/桌面时页面分数会明显下降，所以页面库与运行画面应使用同一窗口模式（建议全屏）。
